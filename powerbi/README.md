# Dashboard Power BI

Dashboard desenvolvido para analisar o comportamento dos segmentos do varejo brasileiro entre julho de 2025 e julho de 2026.

O relatório utiliza dados da Pesquisa Mensal de Comércio (PMC), do IBGE, preparados com Python e consultados por meio do MySQL.

**Indicadores e análises:**
- Crescimento e retração interanual.
- Coeficiente de variação por atividade.
- Evolução mensal do índice de volume de vendas.
- Filtros interativos por segmento.

Ferramenta utilizada: Microsoft Power BI Desktop.
