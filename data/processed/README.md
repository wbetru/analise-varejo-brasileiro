Esta pasta contém a base de dados tratada da Pesquisa Mensal de Comércio (PMC) do IBGE.

Os dados foram organizados e preparados para análise com Python, consultas SQL no MySQL e visualização no Power BI.

**Período analisado:** julho de 2025 a julho de 2026.

**Estrutura:** 208 registros, 16 séries e 13 meses de observações.
